# Пандус к уличной площадке

Съёмный заезд из обрезной доски, чтобы закатывать мотоблок и другую колёсную технику на площадку и скатывать обратно.

## Общая ссылка

**https://arimberg-svg.github.io/pandus-ulichnaya-vykladka/**

Репозиторий: https://github.com/arimberg-svg/pandus-ulichnaya-vykladka

## Что внутри

- Замер порога и расчёт длины пандуса
- Список досок и саморезов
- Чертёж клина, настила и зацепа
- Сборка по шагам и как катить технику
